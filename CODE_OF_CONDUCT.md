# Code of conduct

Treat contributors and users respectfully. Critique ideas and code constructively, acknowledge differing experience levels, and keep discussions relevant to the project.

Harassment, threats, discriminatory remarks, sexual harassment, deliberate disclosure of private information, and sustained disruptive behavior are not acceptable in project spaces.

The maintainer, xichaodong, may edit or remove inappropriate content, limit participation, or ban participants when necessary. Decisions should reflect the behavior and its impact; reports should be handled discreetly.

Report conduct concerns through the repository's private reporting channel when available. Otherwise, request a private contact channel without disclosing personal information in a public Issue. Do not use a security advisory to report ordinary disagreements about code.
